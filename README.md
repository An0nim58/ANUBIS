ANUBIS — это интерактивная консольная утилита на Python для проведения OSINT-исследований и анализа цифрового следа. Инструмент создан в строгом кроваво-красном стиле и объединяет в себе поиск по открытым источникам и базу знаний.

## 🩸 Возможности
* 📚 **Мануалы** — встроенные интерактивные инструкции по OSINT-тактикам и цифровой анонимности.
* 📱 **Поиск по телефону** — проверка сотового оператора, региона и активности WhatsApp.
* 🚗 **Поиск по госномеру авто** — оффлайн-определение региона РФ по коду и генерация OSINT-ссылок.
* 📧 **Поиск по Email** — проверка существования MX-записей домена и линки для поиска утечек.
* ✈️ **Поиск по Telegram** — автоматический анализ инпута (ID/Username) и генерация поисковых запросов.

## 🛠 Установка и запуск

1. Клонируйте репозиторий или скачайте код софта на компьютер.
2. Откройте терминал в папке проекта и установите все зависимости одной командой:
```bash
pip install -r requirements.txt
```
3. Запустите главный файл утилиты:
```bash
python main.py
```
